# 🎵 Music Visualizer

A music visualizer that turns sound into motion. Play music and watch the visuals respond to the audio.

## ✨ Features

- Audio-reactive visual effects
- Suports mp3 for input. Outputs to visual bars and particle spectrum
- First Person Movement and 3D Audio
- PLAY/PAUSE BUTTON

## 🛠️ Built With

- C#
- AudioSource.GetSpectrumData
- 3D Rendering & Particle System

## 🚀 Getting Started

### Prerequisites

- Microsoft Visual Studio, Unity HUB
